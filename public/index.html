Frequently Asked Questions

Everything you need to know

How does the code system work?

When you pick a plan, the system generates a unique 5-digit code for you. Use the same code to log in here AND to activate the PAYME app on the target device.

Is the free tier really free?

Yes. You get a code that never expires and 3 commands total. No payment needed.

How do I upgrade to PRO or VIP?

Tap the PRO or VIP button. It opens WhatsApp. Send your message, we send payment details. After payment, we send you the upgraded code.

Does it work on all Android versions?

Yes. Android 5 through Android 15+. Camera capture uses Camera2 API on modern devices.

Is there an iOS version?

Coming soon. Follow our WhatsApp for updates.

What if I lose my code?

Message us on WhatsApp. We keep records of every generated code.
